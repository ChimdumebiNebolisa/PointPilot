# Product scope

PointPilot is a general-purpose, co-present desktop companion for seeing,
explaining, and pointing at the current external foreground application.

Foreground GIMP 3.x on Windows 11 is the only verified mutation environment.
PointPilot refuses input outside GIMP, refuses sensitive windows, and never
captures its own companion or overlay. It does not offer arbitrary application
control, shell execution, credential entry, payment, publishing, permanent
deletion, file organization, research, memory, routines, providers, MCP, or
external integrations.

The focused loop is: See -> Understand -> Point or Explain -> Guide or Act ->
Verify -> Remain available for correction.
