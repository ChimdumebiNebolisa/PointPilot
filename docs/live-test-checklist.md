# Live test checklist

Use this checklist only after the `pre-live-acceptance` automated baseline has been tagged. Live microphone and GIMP acceptance are intentionally separate from baseline verification.

## Pinned environment

- Windows 11 x64, standard non-administrator interactive desktop session.
- GIMP 3.2.4 using the official `gimp-3.2.4-setup.exe` universal Windows installer from `https://download.gimp.org/gimp/v3.2/windows/`.
- GIMP UI language: English.
- GIMP mode: Single-Window Mode, maximized to the primary display.
- Display: one physical 1920x1080 primary monitor at 100 percent scaling.
- Dock arrangement: default single-window layout with Toolbox and Tool Options visible on the left and Layers visible on the right. Do not undock, resize, or reorder panels during counted runs.
- PointPilot: self-contained `win-x64` package built from the commit named by the local `pre-live-acceptance` tag.
- Fixture: `fixtures/pointpilot-promotional-graphic.ora` freshly generated by `tools/generate-demo-fixture.ps1`.
- Export target: `%USERPROFILE%\Pictures\pointpilot-built-for-focus.png`.

## Reset before every counted run

1. End PointPilot and close the prior fixture in GIMP without preserving test edits.
2. Run `& .\tools\generate-demo-fixture.ps1` from the repository root.
3. Delete the prior export target if it is a disposable test artifact. If it must be preserved, move it manually to an evidence folder and confirm the exact export target no longer exists.
4. Open `fixtures/pointpilot-promotional-graphic.ora` in GIMP 3.2.4.
5. Confirm the Layers panel order is Accents, Product badge, Subtitle — edit this in the demo, Title, Focus visual, Background.
6. Confirm English UI, Single-Window Mode, visible left Toolbox/Tool Options, visible right Layers dock, maximized 1920x1080 window, and 100 percent display scaling.
7. Confirm no modal dialog is open, then place GIMP in the foreground.

## Counted checks

- [ ] Fixture and export target were reset using the steps above; GIMP is foreground and its bounds are stable.
- [ ] One activation enters Listening; the microphone indicator is visible.
- [ ] Five conversational turns remain coherent without another activation.
- [ ] Teach explains the live Layers panel and the pointer overlay is correct; the real cursor remains unchanged.
- [ ] Guide gives one step, waits, recaptures, and recognizes the visible change.
- [ ] “Do it for me” enters Act and preserves the goal and completed steps.
- [ ] One-action test performs exactly one reversible GIMP action, visibly and inside foreground GIMP, then verifies it.
- [ ] Spoken barge-in stops PointPilot speech and gives priority to the new turn.
- [ ] Mid-task correction stops the old task revision before its next atomic action, preserves completed safe work, and replans from a fresh screenshot.
- [ ] Escape stops speech and prevents later queued actions; perform this on a separate resettable subtask.
- [ ] A reversible edit can be undone through native GIMP undo with visible verification.
- [ ] The full hero workflow changes the subtitle to “Built for Focus,” preserves the headline constraint, applies the requested visual treatment, and uses only visible GIMP UI actions.
- [ ] Export waits for confirmation naming the exact action, path, and overwrite risk.
- [ ] The final screenshot supports the requested title, subtitle, layout, and effect result.
- [ ] The exact PNG exists and opens; PointPilot summarizes completion only after screenshot and file checks.
- [ ] No overlay appears in any model-bound screenshot evidence.
- [ ] No operator rescue, hidden automation, GIMP API, plug-in, or prerecorded action was used.

## Repeatability and failure evidence

AC-20 passes only after three consecutive counted successful runs from the reset state. A failure after PointPilot begins Acting breaks the sequence and the next attempt returns to run 1 of 3. A missing prerequisite before Acting is recorded as non-counting.

For every run, retain the completed checklist, UTC timestamps, initial and final GIMP screenshots, PointPilot state/error metadata, the exported PNG path and SHA-256 when created, and a short operator note. Do not retain API keys, `.env.local`, raw microphone audio, full transcripts, model response bodies, or screenshots containing unrelated private data.
