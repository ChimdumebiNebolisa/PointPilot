# Focused PointPilot demonstration

1. Open the promotional fixture in GIMP and start PointPilot with
   `Ctrl+Alt+Space`.
2. Ask, "What app am I in?" PointPilot identifies the foreground target.
3. Ask, "Show me where the Layers panel is." PointPilot explains and points
   without moving the system cursor.
4. Ask, "Point to the Product layer." PointPilot keeps the external target in
   focus.
5. Ask, "Click the Product layer." PointPilot uses one guarded GIMP action and
   requires a visible screenshot change before claiming success.
6. Interrupt while it speaks, then interrupt while it acts. The old task
   revision must stop before the next action and resume only from the new
   screen state.
7. Press Escape to stop speech and future input. Use native GIMP undo when
   appropriate.

Do not present this as arbitrary desktop automation. GIMP is the first verified
control environment.
